# Phase 8 acceptance

Sites are blocked only with the Companion connected (Phase 7 setup). Apps are checked either way.

| # | Do | Expected |
|---|---|---|
| 1 | "focus for 10 minutes on maths" | "Focus on: maths, until …"; Settings > Focus mode shows the session |
| 2 | Open youtube.com in Chrome | The focus page shows your goal and the end time instead of YouTube |
| 3 | Open Discord (or Steam) | First time: a nudge in your chosen tone, the app stays |
| 4 | Bring it to the front again | It is minimised |
| 5 | A third time | It is closed (gently, like close_app) |
| 6 | "how is my focus going?" | Time left, slips so far, and this week's totals |
| 7 | "emergency exit" | "Focus session ended. Everything's unblocked."; YouTube opens again |
| 8 | Start a 5-minute session and wait | At the end a spoken (or shown) summary; the site rules are gone |
| 9 | Start a session, quit ALDREN from the tray, start it again | The session continues until its end time |
| 10 | Start a session, then tray > **End focus session** | Ended |
| 11 | Settings > Focus mode | The last 7 days: sessions, minutes, slips, ended early |
| 12 | "focus for an hour on the report" | The work profile (chat apps allowed) |
