# Phase 8 plan: Focus mode

Status: approved 2026-11-08 (same message). No downloads, no system changes: app enforcement uses window events, website blocking uses the Companion extension's declarativeNetRequest rules.

| Piece | Notes |
|---|---|
| Sessions | "focus for 50 minutes on my thesis": goal, profile (study, work, or your own lists), duration, then enforcement, a break reminder and a summary with stats |
| App enforcement | Blocked app in front: the first slip is forgiven with a nudge, then minimise, then close (its own close button, so it can ask to save); never terminated by default |
| Website enforcement | Blocked sites redirected to a "back to your goal" page by the extension, with an expiry the extension enforces itself, so rules disappear at the end time even if ALDREN crashed; Core also clears leftovers at start |
| Emergency exit | "emergency exit" / "end focus", the tray menu, always works |
| Personality | Gentle, then sarcastic, then dramatically disappointed; never insulting |
| Stats | Sessions, minutes and slips, "how did my focus go this week" |

Deferred: schedules from the calendar, the strict (elevated) tier, Phase 8b webcam presence (optional, opt-in).
